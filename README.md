# scoop-zenith

[![Tests](https://github.com/tonieninja/scoop-zenith/actions/workflows/ci.yml/badge.svg)](https://github.com/tonieninja/scoop-zenith/actions/workflows/ci.yml) [![Excavator](https://github.com/tonieninja/scoop-zenith/actions/workflows/excavator.yml/badge.svg)](https://github.com/tonieninja/scoop-zenith/actions/workflows/excavator.yml)

[Scoop](https://scoop.sh) bucket for [Zenith](https://github.com/tonieninja/zenith-player), an independent desktop player for YouTube Music.

```pwsh
scoop bucket add zenith https://github.com/tonieninja/scoop-zenith
scoop install zenith/zenith
```

This installs the portable build. The manifest updates itself when a new Zenith release comes out.

Zenith is not affiliated with, endorsed by or sponsored by Google or YouTube.
